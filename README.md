# evoNN_UTTT: The Neuroevolution Algorithm Trained on Ultimate Tic-Tac-Toe [ARCHIVED]

This project was an attempt to create a problem-agnostic neuroevolution algorithm. It is tested and developed, initially, for the board game of Naughts and Crosses (Tic-Tac-Toe). Stagnation of progress (possibly due to an evasive bug, or ineffective algorithm design) resulted in this project being archived.

**GitHub Pages Devlog: https://stefanciutac.github.io/stefanciutac_devlog/**

The devlog linked above contains posts discussing system architecture and the rationale behind the design decisions I have made, as well as discussing the project's next steps (the current latest post relating to this project analyses the architecture decisions behind v0.1.0; a post-mortem as to the likely modes of failure will soon be published).
